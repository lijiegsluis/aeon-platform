# Product Enhancement Plan - Aeon Nimbus Intelligence

## Analysis of Current State

The product has a solid foundation with:

- ✅ Clean dashboard layout with metrics
- ✅ Fear & Greed Index
- ✅ Event timeline with phase system
- ✅ Calendar and earnings views
- ✅ Real-time data updates

## Enhancement Opportunities

### 1. **Advanced Filtering & Sorting** (High Value)

- Multi-select phase filters
- Impact score slider
- Date range picker
- Ticker search with autocomplete
- Sort by impact, date, phase, sentiment correlation

### 2. **Smart Alerts & Notifications** (High Value)

- Browser notifications for critical events (D-2 or less)
- Custom alert rules (ticker watching, impact threshold)
- Alert history panel
- Snooze/dismiss functionality

### 3. **Enhanced Visualizations** (Medium-High Value)

- Interactive heat map: days_away (X) vs impact_score (Y), color by phase
- Sparklines showing event density over time
- Sentiment trend chart (7-day rolling average)
- Phase transition animations

### 4. **Ticker Intelligence** (High Value)

- Clickable ticker chips
- Per-ticker event aggregation
- Historical phase performance per ticker
- Correlation between events and ticker sentiment

### 5. **Export & Sharing** (Medium Value)

- Export watchlist as CSV/JSON
- Share specific events (deep links)
- Screenshot/PDF report generation
- API key for programmatic access

### 6. **Watchlist & Favorites** (High Value)

- Personal watchlist with custom tickers
- Star/favorite events
- Notes on events
- Portfolio impact calculator

### 7. **Intelligence Insights** (Very High Value)

- Pattern detection: "Similar events in the past led to..."
- Anomaly detection: unusual event clustering
- Correlation insights: "Events like this typically precede..."
- AI-generated trading scenarios

### 8. **Keyboard Shortcuts** (Medium Value)

- Cmd/Ctrl + K: Quick search/command palette
- Arrow keys: Navigate events
- Space: Quick view event details
- F: Toggle favorites
- Numbers 1-4: Switch tabs

### 9. **Performance & Polish** (High Value)

- Loading skeletons instead of blank states
- Smooth transitions between views
- Optimistic updates
- Error boundaries with retry
- Offline mode indicator

### 10. **Mobile Optimization** (Medium Value)

- Responsive breakpoints
- Touch-friendly interactions
- Swipe gestures
- Bottom navigation for mobile

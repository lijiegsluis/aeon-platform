# Archived docs

These docs described an earlier, more ambitious version of the product plan —
several reference a "Aeon Platform" product and Telegram/data-source
integrations that were never built, and describe this product (now "Aeon
Analysis") under its former working name "Aeon Nimbus Terminal."

They're kept for history, not deleted, but are **not current**. For the
accurate, up-to-date picture of what's actually built and how the products fit
together, see [`AEON_ECOSYSTEM.md`](../../AEON_ECOSYSTEM.md) at the repo root.
